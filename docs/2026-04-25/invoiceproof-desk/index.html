FAQ

How do you access our work artifacts safely?
Least-privilege access only. Usually that means a shared folder plus read-only access to one project system or exported reports. No production credentials required, and NDA is fine.
What needs to be true for this to work well?
You need one supported source of truth for project activity, like Linear, Jira, Asana, ClickUp, Notion, or a clean weekly update doc. If work evidence is spread across random chats with no owner, we will ask you to tighten the input first.
What happens during onboarding?
We define the client-facing pack format, billing cadence, included sections, evidence sources, and approval owner. Most onboarding can be done in under an hour if your project artifacts are reasonably organized.
How long do you retain our materials?
Only as long as needed for active work and template improvement. Default retention is 30 days for exported working files unless you request a shorter or longer window.
