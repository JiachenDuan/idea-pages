FAQ

How do you access our data safely?
We start with exports or read-only access only. No production changes, no write permissions, and we can work inside a shared folder with an agreed retention window.
What do you need before onboarding?
At minimum: one usage export, account owner mapping, and one source of customer context such as CRM notes, support data, or renewal notes. We keep the starter offer to a narrow supported stack so setup stays light.
How long does onboarding take?
Usually under a week for the starter tier. The first pilot report is the main setup step, and later reports get faster once the metric mapping is locked.
How long do you retain customer data?
Only as long as needed for active work, with a default short retention window that we can define upfront. We can also work from customer IDs and redacted exports when possible.
Is this a fit if we already have dashboards?
Yes, if the issue is not raw data availability but the last-mile packaging. We are most useful when teams have data but still lack a repeatable customer-facing value report.
Works best when you already have basic usage and account data. Not a fit if the problem is a completely missing data foundation.
