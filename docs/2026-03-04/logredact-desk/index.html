FAQ

How do you handle access and security?
Least-privilege access only (a shared folder or upload link scoped to the request). No production credentials. Optional NDA. We can work from already-exported artifacts only.
What’s the retention policy?
Default retention is 14 days for active work. We can do shorter/longer, and we’ll delete immediately on request after delivery.
What do you need from us to start?
A clear ‘who is this for and what are we proving’ sentence, plus the artifacts (screenshots/logs/config excerpts). If you have preferred redaction rules, share them; otherwise we propose one for approval.
Can you guarantee you won’t miss something sensitive?
No one can guarantee perfection, so we operate with a strict policy + QA checklist and require your approval before delivery. We also recommend using least-privilege exports and avoiding raw dumps when possible.
How does onboarding work for ongoing packs?
We’ll set a standard request form, file naming conventions, and a reusable redaction policy so future packs take less time and require fewer back-and-forths.
