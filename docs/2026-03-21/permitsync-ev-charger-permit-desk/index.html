FAQ

How do you handle access and security?
We use least-privilege access (shared inbox/portal roles where possible), keep an access log, and avoid storing unnecessary credentials. NDA available.
What do you need before onboarding?
Your permit document checklist, project roster, target cities/AHJs, and one point of contact for escalation/approvals.
How long does onboarding take?
Usually 2-5 business days to set up the first metro playbook and start processing active jobs.
Do you keep our permit/project data forever?
No. We use a defined retention window and can delete data on request or at offboarding.
