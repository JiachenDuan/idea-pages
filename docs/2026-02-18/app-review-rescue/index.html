FAQ

What access do you need? Is this safe?
We only need read access to your public reviews (and optionally a shared doc for drafts). No production credentials. No user PII required. We can sign an NDA and keep an access log.
Do you reply directly from our accounts?
By default, no — we draft replies and you approve/post. If you want us to post, we use least-privilege access and a strict reply playbook.
What do you need from our team to make this work?
A point person for approvals (10–15 min/day) and one engineer/PM to receive the weekly fix brief.
How fast is onboarding?
Usually 60–90 minutes total to align on brand voice, policy boundaries (refunds, data, privacy), and the tag taxonomy.
What’s your retention policy?
We retain only what’s needed to run the weekly briefs (review text snippets + tags) and can delete on request. We avoid storing any user identifiers.
Will this improve retention?
Replying alone doesn’t fix product issues — the value is clustering issues and turning them into a prioritized fix plan. When fixes ship, we can optionally run winback replies to prompt users to update ratings.
We don’t claim results we can’t control. You own final approval for replies and product decisions.
