FAQ

How do you handle security and access?
Least-privilege access only. Usually that means a shared folder, a tracker, and temporary portal access if needed. No production credentials, and NDA is fine.
What do you need before starting?
At minimum: your current security docs, any past questionnaire answers, a named approver, and one place where we can collect evidence. If the docs are messy, we can still start by organizing them.
What does onboarding take?
Usually 60 to 90 minutes of working time across one kickoff, document collection, and approval-path setup. After that, each new request is run through the same workflow.
How long do you retain our materials?
Only as long as needed for active work and the reusable answer bank you approve. We can set a fixed retention window and delete on request.
Is this a fit if we are pre-SOC 2?
Yes, if you already get security requests and want a cleaner process. We do not invent claims. We package what is true, highlight gaps clearly, and keep approvals tight.
Works best when you already have some security materials and a named internal approver. Not a fit if you need a full compliance program built from zero.
