FAQ

How do you handle access and security?
We prefer least-privilege access: shared inboxes, dealer-specific editor roles, or client-submitted update packets. No store admin access unless truly required, and we keep a basic access/change log.
What needs to be true for this to work well?
You need one person who can approve source-of-truth content, plus a current SKU list, asset folder, and dealer/channel list. If the raw data is messy, we can clean that during setup.
How long does onboarding take?
Usually 3-5 business days for the first usable tracker and update queue, depending on SKU count and how fragmented the current files are.
Do you keep our files forever?
No. We keep only what is needed for active work and agreed reporting. We can work under a defined retention window and hand back the organized tracker/assets if you stop.
What if some dealers do not give portal access?
That is common. We can still prepare dealer-ready update packets, email instructions, and a follow-up tracker so your team or rep submits them fast.
