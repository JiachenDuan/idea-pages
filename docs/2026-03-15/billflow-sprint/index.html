FAQ

What access do you need?
Stripe access only, least-privilege (ideally read-only first, then limited admin for configuration). No production database credentials by default. We can work from exports/screenshots for the audit phase.
How do we avoid breaking renewals?
We do a dry run first (shadow invoices / test customers), document all edge cases, and ship a cutover + rollback plan. Renewals are the #1 risk—so the sprint is built around de-risking them.
What are the prerequisites?
A list of current plans/price IDs, how entitlements map to plans, and 10–20 examples of ‘weird’ customers (grandfathered, discounts, annual invoices). If you don’t have this, we’ll help extract it during discovery.
How long does onboarding take?
Usually 60–90 minutes total across 2 short calls (kickoff + packaging review), plus async Q&A. We keep the rest lightweight and documented.
What’s your retention policy?
We keep only what we need to deliver the sprint (configs, exports, checklists). You can choose a retention window; we’ll delete on request after handoff.
