FAQ

How do you handle security and customer data access?
We work from least-privilege shared folders or exports, not production credentials. Access can be time-boxed, NDA-backed, and limited to the exact files needed for the import.
What has to be true before we start?
You need one destination schema, one named internal owner, and a sample source export or clear file format. We start with CSV-based workflows first, not direct database migrations.
What does onboarding look like?
Usually one short kickoff, a source-file intake checklist, and agreement on required fields and import success criteria. After that, most communication happens through a simple blocker list and approval loop.
What is your retention policy?
By default, we keep working files only for the active engagement window plus a short agreed retention period, then delete them. If you need a stricter retention window, we can set that up up front.
