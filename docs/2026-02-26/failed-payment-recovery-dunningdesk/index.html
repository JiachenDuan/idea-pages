FAQ

What access do you need?
Read-only billing access where possible (Stripe/Chargebee reporting) plus permission to configure dunning templates. No bank access. We can work from exports if needed.
Will this annoy customers?
We design for ‘calm reminders’ first, with clear escalation rules and stop conditions. You approve any firmer copy and any service-pause policy.
What prerequisites should we have?
A billing system (Stripe/Chargebee) and a clear definition of ‘active’ vs ‘past due’. If you invoice manually, we can still install a cadence and reporting, but results depend on invoice hygiene.
How fast is onboarding?
Typically 60–90 minutes total across a kickoff call + access setup. We aim to ship the install in 14 days.
What’s your retention policy?
We retain only what’s needed to operate (templates + aggregated metrics). Any exports you share can be deleted on request; we can set a default retention window (e.g., 30 days).
