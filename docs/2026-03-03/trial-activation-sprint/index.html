FAQ

What access do you need?
Best case: read-only access to analytics (Amplitude/Mixpanel/Heap), your email/in-app tool (Customer.io/Intercom), and a staging environment for copy. No production credentials required. Least-privilege only.
What if we don’t have good tracking yet?
That’s common. We’ll start with a minimal event schema for activation milestones and the key onboarding steps, then add deeper tracking in week 2.
What prerequisites make this work best?
You have at least ~100 trials/month (or high-value trials), a clear ICP, and one primary ‘first success’ job-to-be-done. If onboarding is multi-product, we’ll narrow to one segment first.
How fast is onboarding?
You’ll spend ~60–90 minutes total: one kickoff, one mid-sprint review, and a final handoff. Everything else is async with a shared checklist.
How do you handle retention and data deletion?
We keep only what we need to do the work. By default we can operate from exports/snapshots and delete within a defined window (e.g., 30 days) on request.
