FAQ

How do you access our systems safely?
Least-privilege only. We can work from exported examples, approved traces, or a sandbox dataset first. No production write access is required for the initial workflow.
What do we need before onboarding?
One important workflow, one internal owner, 20-100 representative examples, and agreement on what a bad failure looks like. We start narrow on purpose.
How long does onboarding take?
Usually 3-5 business days for the first workflow. The goal is not a giant eval platform — it is one usable release gate the team will actually trust.
How long do you retain our data?
Only as long as needed for the active engagement and agreed reporting history. We can work with redacted examples where possible and delete artifacts on request.
What if we need deeper ML or prompt work?
We can flag likely failure patterns, but the offer is eval operations and release reporting — not model training, deep prompt engineering, or research consulting.
