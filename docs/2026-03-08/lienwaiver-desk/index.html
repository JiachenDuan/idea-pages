FAQ

Do you need access to our accounting system?
Not required. We can work from PDFs/CSVs and a shared Drive. If you want, we can use read-only exports from QuickBooks/Xero. We never need bank access.
How do you handle security and sensitive financial docs?
Least-privilege access (a single shared folder + portal login if needed), optional NDA, and a retention window (default: keep only what’s needed for active jobs).
What’s required from us each time?
Invoice amount + billing period, job name/number, and any required backup docs (timecards, receipts, photos) if your GC requires them. We’ll give you a one-page checklist per customer/portal.
Do you choose the waiver type / language?
We prepare the waiver using your preferred templates and the correct conditional/unconditional flow based on payment status, but we’re not your attorney. If your state/job has special language, we recommend attorney-reviewed templates.
How fast is onboarding?
Usually 60–90 minutes of your time and 1–2 business days to set up your first job template + folder structure.
How do we measure ROI?
We track rejection rate, average days from ‘invoice ready’ → ‘submitted’, and days-to-acceptance. The goal is fewer kickbacks and faster approvals.
