FAQ

How do you handle access and document security?
We use least-privilege access only: shared folder, email thread, or a limited project workspace. No accounting logins or broad system access required. NDA is fine.
What do you need from us to get started?
One active project, the contract closeout requirements or submittal list, current document folder, and one named PM or coordinator who can unblock edge cases.
How long does onboarding take?
Usually 1-2 business days to set up the checklist, naming rules, and first project tracker. We can often start cleanup work the same week.
What if a vendor or foreman still has not sent the missing docs?
We keep the blocker tracker current and chase the named source, but we do not invent missing artifacts. You always see exactly what is still open and who owns it.
What is your retention policy?
We retain only the working files needed for active projects unless you ask for a longer archive window. On offboarding, we return organized files and delete our working copies on the agreed schedule.
