## FAQ
- **What access do you need?**: We prefer read-only exports (CSV/PDF) from each system, provided by your admins, into a dedicated folder. If needed, we can use delegated admin access with least privilege and an access log. No production credentials required.
- **What are the prerequisites for a smooth review?**: A clear owner per system, a list of current employees/contractors, and a decision-maker who can approve removals/downgrades. If you have SSO/IdP (Okta/Google), even better.
- **How does onboarding work and how long does it take?**: Onboarding is usually 60–90 minutes total across 1–2 calls. We set up the export checklist, folder structure, reviewer list, and approval workflow so future quarters are repeatable.
- **Do you remove access for us?**: Only if you choose an ‘assisted remediation’ add-on and only after explicit written approval per change. By default, we provide a prioritized remediation list and you execute the changes.
- **What’s your data retention policy?**: Default is 30 days after delivery for working files, with a customer-controlled ‘evidence archive’ stored in your own Drive. We can shorten retention to 0 days (delete immediately after delivery) on request.
