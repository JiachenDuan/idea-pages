FAQ

What access do you need?
Least-privilege only: a billing/subscription export (CSV), a shared inbox or alias for vendor comms, and any existing contract PDFs. No production credentials. Optional NDA.
Can you cancel tools for us?
We can execute cancellations, but only with written approval per tool (email confirmation is fine). We always capture cancellation receipts and update the audit log.
How do you prove savings?
We track baseline (current contract/seat count), the negotiated outcome (new rate/term), and the monthly delta. We report verified savings with links to vendor confirmations.
What if vendors won’t negotiate?
We still win by right-sizing seats, changing terms (monthly vs annual), consolidating overlapping tools, and using credible alternatives as leverage.
What’s onboarding effort?
Usually 60–90 minutes total: one kickoff call + exporting a subscription list + dropping contracts into a folder. After that, we run the queue and ask for approvals when needed.
What’s your retention policy?
We retain only what we need to operate renewals. You can set a retention window (e.g., 30/60/90 days) and request deletion at any time.
