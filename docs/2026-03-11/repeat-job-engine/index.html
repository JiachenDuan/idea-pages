FAQ

Do we need customer consent to text?
Yes. We’ll review your current consent capture (forms, invoices, booking flow). We use opt-out keywords (STOP) and conservative frequency. If SMS isn’t safe, we can run email-first.
What access do you need?
Least-privilege only: a CSV export of customers (no payment info), and limited access to your messaging tool (or we set up a dedicated sender). No production credentials. NDA optional.
What systems do you support?
We start with CSV exports from Jobber, Housecall Pro, ServiceTitan, or QuickBooks, plus a simple messaging stack. If you’re on something else, we can still start with an export.
How long does onboarding take?
Usually 60–90 minutes total across 2 short sessions: export + segment choices + copy approval.
What’s your retention policy for our customer list?
Default: 30-day retention for active work, then deletion on request. We can also run entirely in your tools so data never leaves your accounts.
