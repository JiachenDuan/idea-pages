FAQ

How do you handle security and access?
Least-privilege only. We can work from screenshots, exported metadata, shared docs, and temporary admin access when necessary. No production credentials are stored outside approved systems.
What prerequisites need to be true?
Your product must already support the target SSO flow in a basically working state. You also need one internal technical owner and one customer-side admin who can answer IdP questions.
How long does onboarding take?
Usually less than 1 business day. We start with a short kickoff, an intake form, and a shared checklist so the first customer-facing message goes out quickly.
Do you support SCIM or provisioning?
Yes, when the product already supports it. We can coordinate mapping, test cases, and handoff, but we do not build missing provisioning features.
What is your retention policy?
By default, we keep only the artifacts needed for the active setup and delete working copies after handoff unless you ask us to retain a reusable playbook longer.
